# SQLite bundled library notice

The `rusqlite` dependency is configured with its `bundled` feature. The bundled SQLite core library is dedicated to the public domain by its authors. SQLite's official copyright page states that the source code and deliverable library are public domain and may be copied, modified, compiled and distributed for commercial or non-commercial use.

Official source: https://www.sqlite.org/copyright.html

The `rusqlite` wrapper itself is MIT-licensed; see `rusqlite-MIT.txt`.
